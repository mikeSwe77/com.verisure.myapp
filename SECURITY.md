# Security policy

This app stores your Verisure credentials on your Homey and can arm and disarm your alarm, so
security reports are taken seriously.

**Please don't open a public issue for security problems.** Report them privately through
[GitHub's private vulnerability reporting](https://github.com/mikeSwe77/com.verisure.myapp/security/advisories/new)
on this repository. Include what you found and how to reproduce it; never include real passwords,
alarm codes, session cookies or installation IDs.

You'll get a reply as soon as possible, and a fix will be released before the details are made public.

Only the latest version of the app is supported.
